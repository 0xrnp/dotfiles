# Personal agent standards

Read and follow `~/ai-standards/AGENTS.md`.

For non-question work when no skill was named, read
`~/.agents/skills/using-skill-guide/SKILL.md` and load only relevant skills.

Repository instructions outrank personal skills. Questions are read-only.
For non-trivial changes, present a file-level plan and proceed in the same
turn. Keep the requested scope, verify with repository evidence, and report
only checks that actually ran. Pause for a material user choice or an action
that needs separate authorization. Respect host-provided worktrees.
